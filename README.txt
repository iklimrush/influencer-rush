INFLUENCER RUSH - TELEFON/TABLET PWA

Bu klasör, oyunu Android/iPhone/tablet ana ekranına eklenebilir web uygulaması olarak yayınlamak için hazırlanmıştır.

ÖNEMLİ:
- PWA kurulum ve çevrimdışı önbellek özellikleri HTTPS üzerinden yayınlandıktan sonra çalışır.
- ZIP'i telefonda açmak tek başına uygulama kurulumu yapmaz.
- index.html oyunun mevcut HTML sürümüdür.
- Ücretsiz kolay seçenek: GitHub hesabında yeni bir repository oluştur, bu klasördeki dosyaları yükle (index.html kökte olmalı), Settings > Pages > Deploy from a branch > main / root seç. Yayınlanan HTTPS adresini telefonda aç.
- iPhone: Safari > Paylaş > Ana Ekrana Ekle.
- Android: Chrome menüsü > Uygulamayı yükle veya Ana ekrana ekle.
- Bilgisayardaki .exe telefonlarda çalışmaz.
